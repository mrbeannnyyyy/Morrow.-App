# Changelog

## 1.0.8-beta.7

- Adds matching bookmark, history, and shortcut suggestions while you type.
- Adds live Google search suggestions to the home search and address bar.
- Improves shortcut-card hover and keyboard-focus feedback.
- Separates beta installs and beta update checks from the public app.
- Shows the beta channel and sends beta update actions to the beta download page.
- Keeps the new-tab page visible in shorter windows and animates the download affordance.


## 1.0.7

- Shows release notes the first time a new app version opens.
- Adds a default browser control in Setup & preferences.
- Adds a browsable release history and a Mac installation guide to the website.


## 1.0.6

- Repackaged with an ad hoc macOS signature for the manual Gatekeeper approval flow.


## 1.0.5

- Added automatic checks for newer Morrow releases with a download-page shortcut.
- Added release notes and a latest-version macOS installer page to the website.


## 1.0.4

- Added a short branded intro each time the app opens.
- Added subtle, reduced-motion-aware transitions when opening tabs and the library.

## 1.0.3

- Fixed the top tab bar so its background and borders follow dark mode.

- Fixed startup failure caused by registering the browser import IPC handlers twice.
- Refreshed the browser chrome and new-tab page.
